## 1. 产品目标

**一句话**：把 v1 的固定面板重构为「滑条悬浮物」——一条常驻最顶层、可拖拽、贴左/右屏幕边缘自动收缩的 iOS 音量条式细长滑条，鼠标靠边即弹出完整滑条、直接拖动调节 SDR 内容亮度；所有交互动效以 spring 阻尼曲线对标 iOS 顶尖手感。

**三个正交目标**

| # | 目标 | 说明 |
| --- | --- | --- |
| G1 | 零感知常驻 | 滑条悬浮物常驻最顶层但不挡工作流；贴边后仅露一条窄边，鼠标靠边即弹出，不打断任何前台应用 |
| G2 | 一步调亮度 | 鼠标靠边 → 弹出完整滑条 → 直接拖动拇指，全程 ≤ 1 次拖拽即可改变亮度并真实生效（复用 v1 已验证写入链路） |
| G3 | iOS 级手感 | 贴边收缩、鼠标唤出、拇指跟手、松手阻尼回弹、数值滚动，全部 spring 非线性、有物理反馈、跟手；扁平化纯色视觉 |

**明确的非目标（Out of Scope，与 v1 一致）**
- 不做 HDR 开关本身的控制（仅读取状态 + 跳转系统设置）
- 不做显示器硬件 OSD 亮度/对比度控制
- 不做色彩管理 / ICC / 色域切换
- 不做联网与数据上报

## 2. 用户故事

| # | 用户故事 |
| --- | --- |
| US1 | 作为 HDR 常开用户，我希望屏幕上有一条常驻的滑条悬浮物，贴边后自动收缩只露一点边、鼠标一靠近就弹出来，以便它既随时可用又不挡我正在看的窗口 |
| US2 | 作为对亮度敏感的用户，我希望滑条弹出后就能直接拖动拇指调亮度，以便手感跟 iOS 音量条一样丝滑、无顿挫、无多余步骤 |
| US3 | 作为经常换位置的用户，我希望这条滑条能被拖到屏幕左缘或右缘并吸附，以便它总停在我最顺手的一侧 |
| US4 | 作为讨厌"显示改了实际没改"的用户，我希望 HDR 关闭或写入失败时滑条给出明确提示，以便知道该去开 HDR 或改用系统设置 |

## 3. 需求池

图例：**P0** 必须（MVP 阻塞）｜**P1** 应该｜**P2** 可选。
每条需求均须**可执行、可验收**，验收标准以真机可复现为准。

### P0（必须）

| ID | 需求描述 | 验收标准 |
| --- | --- | --- |
| P0-1 | **滑条悬浮物窗口**：单窗口，细长垂直胶囊（宽 44px × 高 220px、圆角 22px），无边框、最顶置顶（Always-on-top）、不进 Alt-Tab、不抢焦点、透明背景（仅胶囊内容不透明），整窗可被拖拽移动 | 胶囊圆润无锯齿（DPI 缩放下）；置于任意前台应用之上；拖拽不触发系统焦点抢占 |
| P0-2 | **滑条视觉**：深色扁平，纯色底 `#1C1C1E` + 1px 细描边；顶部单色扁平 SVG 太阳图标 + 底部当前亮度百分比数字，中部垂直滑块；**禁止 emoji、禁止渐变、禁止重阴影** | `grep` 源码零 emoji；CSS 无 `gradient` / 无多层 `box-shadow`；图标为内联 SVG |
| P0-3 | **拖拽移动 + spring 吸附**：按住滑条非拇指区域拖动，1:1 跟随鼠标（跟手、无延迟、无缓动）；松手后 spring 吸附——落在屏幕左/右边缘 12px 内则贴边隐藏，否则停留在松手位置 | 拖动全程不脱手；松手动画为 spring 曲线；越界（拖到多屏外）自动拉回可视区 |
| P0-4 | **贴边自动隐藏**：滑条贴到屏幕左/右边缘后，整体缩入屏外、仅露出 16px 宽的边条；收缩动画为 spring 缓出 | 隐藏后露出部分恒为 16px 边条，无跳变；隐藏/恢复全程丝滑 |
| P0-5 | **鼠标靠边自动弹出**：滑条处于隐藏态时，鼠标移动到所贴边（进入 20px 触发带）→ 滑条 spring 弹出恢复完整胶囊；鼠标移出触发带并离开滑条 → 延迟 600ms 后 spring 缩回 | 弹出/缩回稳定触发，不误触（仅在所贴边触发）；快速进出不抖动（有防抖） |
| P0-6 | **弹出即调值**：弹出后滑条即为完整可交互形态，拇指可直接按下拖动调亮度，**无需二次点击/展开** | 鼠标靠边弹出后立即可拖拇指，无额外步骤 |
| P0-7 | **亮度调节真实生效**：垂直滑块拇指拖动即时写入 SDR 白电平（复用 v1 `SET_SDR_WHITE_LEVEL` 链路 + `percent=(raw-1000)/50` 换算），范围 0–100%，与系统滑块语义对齐 | 拖动过程画面亮度实时跟随；松手后打开系统设置滑块读数与本工具一致（±1 档内） |
| P0-8 | **拇指跟手 + 阻尼回弹**：拇指拖动 1:1 直接映射（无缓动、零延迟）；松手后若有系统吸附（值被对齐到更粗粒度），拇指 spring 磁吸到系统实际值而非跳动回弹 | 拖动 60fps 无卡顿；松手不回弹不跳动，磁吸平滑 |
| P0-9 | **数值滚动动画**：亮度百分比数字随调节纵向滚动切换（如 iOS 滚动数字），数值变化时以 80ms/档滚动 + 末尾 overshoot 阻尼 | 数值滚动与拇指位置同步，无闪烁、无截断 |
| P0-10 | **读取当前值 + 双向同步**：滑条弹出时从系统读取当前真实值；系统设置改动后本工具刷新同步 | 弹出时显示值 == 系统当前值；双方互改均可互相可见 |
| P0-11 | **HDR 未开启降级**：检测到 HDR 关闭时，滑条切换为警告态（图标变橙色 + 滑块禁用 + "前往系统设置开启 HDR" 入口），而非静默失败 | 关闭 HDR 后滑条刷新即进入提示态；点击入口跳转系统 HDR 设置 |
| P0-12 | **写入失败兜底**：写入失败/权限不足时，拇指回弹到原值 + 滑条附近 Toast 提示原因 + "复制诊断信息"入口 | 失败不留下"显示已变、实际未变"错觉；诊断信息含错误码/路线/显示器路径 |
| P0-13 | **动效统一 spring**：所有显隐、弹出、收缩、吸附动画使用 spring 阻尼曲线，主曲线 `cubic-bezier(0.175,0.885,0.32,1.275)`（overshoot 弹出），辅助沉降曲线 `cubic-bezier(0.32,0.72,0.24,1)`（无 overshoot 吸附）；时长见第 4 节 | 无线性/生硬动画；过渡动画均有物理反馈；曲线变量统一定义于 token |
| P0-14 | **全扁平视觉**：纯色底、1px 细描边、无渐变堆叠、无重阴影（最多一层极轻投影或零投影）；深色主题；单色扁平 SVG 图标；**禁止 emoji** | 视觉走查通过；CSS 无渐变/多重阴影/毛玻璃残留；代码零 emoji |

## 4. UI 设计稿

> 以下线框中所有图形符号（☀ ● ▍══ ⚠ 等）**仅为排版占位、标注图标/元素槽位**，实际实现必须替换为**单色扁平 SVG 图标**，禁用 emoji 或字体符号。

### 4.1 单窗口形态（架构约定）

v2 采用**单一窗口**，滑条本身就是悬浮物，无独立球：

| 项 | 规格 |
| --- | --- |
| 窗口类型 | 无边框、无标题栏、Always-on-top、不抢焦点（拖拽/调节时除外）、不进 Alt-Tab、透明背景（仅胶囊内容不透明） |
| 形态 | 细长**垂直胶囊**，与 iOS 17 音量 HUD 同形态 |
| 尺寸 | 宽 **44px** × 高 **220px**，圆角 **22px**（胶囊） |
| 隐藏边条 | 贴边后仅露 **16px** 宽边条（窄边样式） |
| 动效 | 统一 spring（见 4.6） |

> 热区约定（关键）：**拖动拇指（圆形 24px 区域）→ 调节亮度**；**拖动滑条其余区域（图标、轨道空白、边框、背景）→ 移动整个悬浮物**。两手势互不干扰。

### 4.2 滑条悬浮物状态

**默认态（完整停靠/自由悬浮）**

```
        ┌────────┐
        │   ☀    │   ← 亮度太阳 SVG 20px，主色 #F5F5F7
        │        │
        │  ══    │   ← 已填充轨道 #0A84FF（自拇指向上）
        │  ▍     │
        │  ●     │   ← 拇指，直径 24px，白色
        │  ▍     │
        │  ──    │   ← 未填充轨道 rgba(120,120,128,0.32)
        │        │
        │  62%   │   ← 百分比 13px，次级色
        └────────┘
        宽 44px · 高 220px · 圆角 22px
```

- 布局（自上而下）：亮度图标（20px）→ 垂直滑块（含拇指）→ 百分比数字（13px），垂直居中排布
- 轨道：垂直，宽 4px，圆头；**底端 = 0%，顶端 = 100%**，拇指向上拖动增大亮度
- 已填充段：`#0A84FF`；未填充段：`rgba(120,120,128,0.32)`
- 拇指：`#FFFFFF` 圆形，直径 24px（拖拽中放大到 28px + 微弱高光描边）
- 底色 `#1C1C1E` 纯色，1px 细描边 `rgba(255,255,255,0.10)`

**悬停态（hover）**

- 滑条 `scale 1.04`，描边提亮至 `rgba(255,255,255,0.20)`，图标微亮
- 200ms spring 过渡

**拖拽移动态（dragging-window）**

- 按住非拇指区域拖动，滑条 `scale 1.08`，描边提亮至 `#0A84FF`（指示"正在移动"）
- 滑条 1:1 跟随鼠标，无缓动无延迟
- 进入屏幕左/右边缘 12px 吸附带时，该侧显示一条浅蓝吸附引导线

**贴边隐藏态（docked-hidden，仅左/右）**

```
屏外 ┄┄┄┄┄┐
       ╭──┼──╮        ← 仅露 16px 窄边（右侧贴边示例）
       │  ┃  │        ← 窄边样式：深色底 + 细描边 + 竖排亮度指示
       │  ┃  │
       ╰──┼──╯
      屏幕边缘
```

- 滑条沿所贴边平移缩入屏外，仅露 16px 宽窄边
- 窄边样式：深色底 `#1C1C1E` + 细描边 + 居中迷你亮度指示条（4px 宽竖条，长度映射当前亮度 0–100%）
- 收缩动画：280ms `cubic-bezier(0.175,0.885,0.32,1.275)`（轻微 overshoot 后沉降）

**弹出态（从隐藏恢复）**

- 鼠标进入所贴边 20px 触发带 → 滑条 spring 弹出恢复完整胶囊（即默认态）
- 弹出动画：280ms 主 spring 曲线；鼠标移出触发带并离开滑条 → 延迟 600ms 后缩回

**调值态（dragging-value）**

- 拖动拇指：1:1 跟手（无缓动）；写入节流 ≥30ms + 整数 percent 去重（复用 v1 控制器）
- 数值随调节纵向滚动（rolling number），80ms/档 + 末尾 overshoot
- 松手：若系统值被吸附 → 拇指 spring 磁吸到系统实际值（120ms，不跳回弹）

**HDR 未开启态**

```
        ┌────────┐
        │   ⚠    │   ← 警告 SVG 橙色 #FF9F0A
        │  HDR   │
        │  未开启 │
        │        │
        │ 前往设置│   ← 主按钮（蓝底白字）
        └────────┘
```

- 滑块禁用置灰；警告图标 `#FF9F0A`；"前往系统设置开启 HDR" 按钮跳转系统 HDR 设置
- 贴边隐藏态下，窄边指示条同样变为橙色，提示异常

### 4.3 弹出动画

- 从所贴屏边展开：`scale 0.82→1` + `opacity 0→1`，240ms `cubic-bezier(0.175,0.885,0.32,1.275)`（overshoot 回弹）
- 弹出后滑条紧贴屏幕边缘（内侧 8px 内边距），垂直位置保持在贴边前的位置

### 4.4 贴边与弹出规则（仅左/右）

| 停靠状态 | 行为 |
| --- | --- |
| 贴左边缘 | 滑条缩入屏幕左侧屏外，仅露 16px 窄边；鼠标靠近左缘 20px 触发带 → 向右弹出 |
| 贴右边缘 | 滑条缩入屏幕右侧屏外，仅露 16px 窄边；鼠标靠近右缘 20px 触发带 → 向左弹出 |
| 自由悬浮（未贴边） | 滑条完整常驻显示，不自动隐藏；仍可拖拽 |
| 越界纠正 | 滑条被拖离可视区或分辨率变化后，自动拉回最近边缘 |

> 底部、顶部不参与贴边隐藏，避免与任务栏或系统 HUD 冲突。

### 4.5 配色方向（深色扁平）

| 角色 | 色值 |
| --- | --- |
| 滑条底色 | `#1C1C1E`（纯色，不透明，无毛玻璃） |
| 细描边 | `rgba(255,255,255,0.10)`（悬停/拖拽提亮至 0.20 / `#0A84FF`） |
| 主文本 / 主图标 | `#F5F5F7` |
| 次级文本（数字） | `rgba(235,235,245,0.60)` |
| 强调色（已填充轨道/拖拽描边） | 系统蓝 `#0A84FF` |
| 危险/警告（HDR 未开启） | `#FF9F0A` |
| 滑块轨道未填充 | `rgba(120,120,128,0.32)` |
| 滑块拇指 | `#FFFFFF` |
| 隐藏边条迷你指示 | 正常 `#0A84FF` / 异常 `#FF9F0A` |

### 4.6 动效 token（统一 spring）

| Token | 曲线 | 用途 |
| --- | --- | --- |
| `--spring-pop` | `cubic-bezier(0.175, 0.885, 0.32, 1.275)` | 弹出 / 显隐 / 数值滚动末尾（overshoot 回弹） |
| `--spring-settle` | `cubic-bezier(0.32, 0.72, 0.24, 1)` | 贴边收缩 / 吸附 / 磁吸沉降（无 overshoot） |
| 拇指拖动 | 无缓动（1:1 直接映射） | 跟手，零延迟 |
| 松手回弹 | 物理阻尼（若系统吸附则磁吸） | 不跳变 |

## 5. 产品决策

以下交互细节作为当前版本的实现基线。

| # | 设计项 | 决策 |
| --- | --- | --- |
| Q1 | 悬浮物默认显示什么 | **不用球**——砍掉圆形加速球形态，滑条本身就是悬浮物（iOS 音量条式细长胶囊） |
| Q2 | 贴边隐藏贴哪几边 | **仅左 / 右**（底部/顶部不参与贴边隐藏） |
| Q3 | 滑块出现位置 | **滑条即悬浮物**——不设「球 + 滑块」两步交互，滑条常驻、贴边隐藏、鼠标靠边弹出、弹出即完整滑条直接拖 |
| Q4 | 是否保留 v1 托盘 / 热键 / 自启 | **托盘保留**（设置/退出出口）；**热键、自启设为可选、默认关闭** |
| Q5 | 垂直滑块方向 | 底 0% → 顶 100%（上拉调亮，与 iOS 音量一致） |
| Q6 | 预设档位是否保留 | 保留三档（白天 80% / 观影 60% / 夜间 30%），长按滑条呼出 |
| Q7 | 滑条默认贴哪侧 | 首次启动默认右缘，之后记住用户拖放位置 |
| Q8 | 鼠标唤出触发带宽度 | 20px + 600ms 收回延迟防抖 |
| Q9 | 尺寸 | 按滑条规格（44px × 220px 胶囊），不设独立球尺寸 |
| Q10 | 窗口方案 | 单窗口（滑条即悬浮物，无球窗口） |
| Q11 | 精确数值输入 | v2 只读数值，拖动调节；精确输入下放到 P2 |
