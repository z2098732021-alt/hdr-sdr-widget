---

## 1. 产品目标

**一句话**：Windows 调节"SDR 内容亮度"需要 5~7 步点击（设置 → 系统 → 显示 → HDR → 展开 → 拖滑块），本产品把它压缩为 **1 步**：随时呼出一个毛玻璃悬浮面板，直接拖动滑块/按快捷键调节当前显示器的 SDR 白电平，并支持白天/夜间/观影等场景一键切换。

**三个正交目标**

| # | 目标 | 说明 |
| --- | --- | --- |
| G1 | 极速可达 | 任意界面下 1 次操作（快捷键 / 托盘点击）即可开始调节，≤300ms 完成面板呈现 |
| G2 | 与系统一致 | 数值语义与系统设置滑块完全对齐，本工具改动后打开系统设置应看到滑块同步移动（含多显示器各自独立） |
| G3 | Apple 级质感 | iOS Liquid Glass 深色主题、圆角、backdrop-filter 毛玻璃、spring 动效、单色扁平 SVG 图标，无半成品/占位符 |

## 2. 用户故事

| # | 用户故事 |
| --- | --- |
| US1 | 作为 HDR 常开用户，我希望用全局快捷键一键呼出悬浮面板，以便不必打开系统设置就能立刻调亮/调暗 SDR 内容 |
| US2 | 作为白天在明亮环境下办公的用户，我希望点一下"白天"预设就能跳到高亮度档，以便省去每次手动微调 |
| US3 | 作为夜间使用者，我希望一键切到"夜间"低亮度档，以便快速护眼而不被 HDR 桌面刺眼 |
| US4 | 作为观影用户，我希望切到"观影"档获得一个中间偏亮的稳定值，以便 SDR 视频/网页内容亮度自然 |
| US5 | 作为双显示器用户，我希望面板能选择目标显示器，并且默认跟随鼠标所在显示器，以便不用先记住"我刚才调的是哪块屏" |
| US6 | 作为对精度敏感的用户，我希望既能拖滑块也能直接输入精确数值并用 ±步进微调，以便复现某个特定亮度值 |
| US7 | 作为开机即用型用户，我希望程序开机自启并常驻托盘、记住上次面板位置，以便每次使用都在熟悉的位置 |
| US8 | 作为普通用户，我希望在系统 HDR 关闭或写入失败时看到明确提示而不是静默无效，以便知道该去开 HDR 或改用系统设置 |

## 3. 需求池

图例：**P0** 必须（MVP 阻塞）｜**P1** 应该｜**P2** 可选

### P0（必须）

| ID | 需求描述 | 验收标准 |
| --- | --- | --- |
| P0-1 | **托盘常驻**：程序启动后常驻系统托盘，左键单击托盘图标切换面板显示/隐藏 | 托盘图标为单色扁平 SVG；左键单击 ≤300ms 内面板出现/消失；关闭面板不退出进程 |
| P0-2 | **全局快捷键呼出**：默认 `Ctrl + Alt + B`（可在设置中改），任意前台应用下生效 | 快捷键注册全局生效，无焦点抢占；系统占用冲突时提示冲突 |
| P0-3 | **悬浮面板**：无边框、圆角、Always-on-top、深色毛玻璃，宽度 320px 固定 | 见第 4 节 UI 设计稿；DPI 缩放下不模糊、无锯齿 |
| P0-4 | **亮度滑块**：拖动即时写入并生效，滑块范围与系统滑块一致（默认 0–100%） | 拖动过程画面亮度实时跟随，无卡顿、无闪烁；松手后值被系统保留 |
| P0-5 | **数值显示**：滑块右侧显示当前值，默认百分比 `%`，可切换 nits / 倍数（×） | 三种单位切换后数值换算正确；与系统设置滑块读数一致性由架构师实测校准 |
| P0-6 | **精确输入**：数值可点击后直接键入，回车确认；范围外输入自动钳位并回弹提示 | 输入 150 → 自动钳到 100；非法字符被拒绝 |
| P0-7 | **步进微调**：数值两侧 `−` / `+` 按钮，步进 1（按住 Shift 为 5，可配置） | 单击 ±1，长按连续步进；到边界时按钮置灰 |
| P0-8 | **读取当前值**：面板打开/切换显示器时，从系统读取并显示当前真实值 | 打开面板显示的值 == 系统设置当前值（±1 档误差内） |
| P0-9 | **HDR 未开启降级**：检测到 HDR 关闭时，面板显示提示态（滑块禁用 + 一行说明 + "去开启 HDR"跳转按钮），而非静默失败 | 关闭 HDR 后面板刷新即进入提示态；点击按钮打开 设置 → 系统 → 显示 → HDR |
| P0-10 | **写入失败兜底**：写入返回失败/权限不足时，滑块回弹到原值并 Toast 提示原因 | 失败时不留下"显示值已变、实际未变"的错觉；提供"复制诊断信息"入口 |
| P0-11 | **上次位置记忆**：面板关闭时记录屏幕坐标，下次在同一位置打开；越界时自动纠正回可视区 | 重启后位置保持；换显示器/分辨率变化后不出现在屏幕外 |
| P0-12 | **Apple 风格与动效**：Liquid Glass 深色、圆角 16px、backdrop-filter 毛玻璃 + 细高光描边 + 柔和投影；spring 曲线 `cubic-bezier(0.175,0.885,0.32,1.275)`；图标全部单色扁平 SVG，禁用 emoji | 视觉与动效通过设计师走查；代码中无 emoji、无 placeholder 文本 |

## 4. UI 设计稿

### 4.1 形态与尺寸

| 项 | 规格 |
| --- | --- |
| 窗口类型 | 无边框、无标题栏、Always-on-top、不抢焦点（面板内输入时除外）、不进 Alt-Tab |
| 尺寸 | 宽 **320px**，高 **自适应**（默认态 ≈ 208px；HDR 关闭提示态 ≈ 148px） |
| 圆角 | 外圆角 **16px**，内控件圆角 10–12px |
| 阴影 | 外投影 `0 12px 40px rgba(0,0,0,.45)` + 内描边 `1px rgba(255,255,255,.10)` |
| 材质 | `backdrop-filter: blur(28px) saturate(160%)`，背景 `rgba(28,28,30,.72)` |
| 动效 | 出现：scale 0.94→1 + opacity 0→1，220ms `cubic-bezier(0.175,0.885,0.32,1.275)`；隐藏反向 160ms ease-out |
| 图标 | 单色扁平 SVG（1.6px stroke，round cap），主色 `#F5F5F7`，次级 `rgba(235,235,245,.55)`。**禁止 emoji** |

> 说明：下方线框中出现的所有符号（⚙ ✕ ☀ ☾ ▣ ⚠ ⠿ ⓘ ● ○）**仅为排版占位，标注图标槽位**，实际实现必须替换为单色扁平 SVG 图标，不得使用 emoji 或字体符号。

### 4.3 精确输入态（点击数值后展开）

```
│  ┌─────────────────────────────────────────┐  ┌───┐┌────┐┌───┐│
│  │ ●━━━━━━━━━━━━━━━━━━━━○──────────────────│  │ − ││ 62 ││ + ││
│  └─────────────────────────────────────────┘  └───┘└────┘└───┘│
                                                    ↑ 点击后进入
                                                      输入态（光标、
                                                      选中全选、回车确认）
```

- `−` / `+`：单击 ±1；按住 Shift 单击 ±5；长按 400ms 后连续步进（间隔 60ms）
- 到 0 或 100 时对应按钮 opacity 降至 .3 并禁用

### 4.4 HDR 未开启提示态

```
┌────────────────────────────────────────────────────────┐
│  ⚠ HDR 未开启                                     ⚙   ✕   │
│                                                        │
│  SDR 内容亮度仅在 HDR 开启时可用。                      │  14px / 次级色
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │           前往系统设置开启 HDR                    │  │  h=36 主按钮
│  └──────────────────────────────────────────────────┘  │
│  ● 检测到 0 台 HDR 显示器                               │  11px / 三次级色
└────────────────────────────────────────────────────────┘
```
滑块、预设行在提示态下**隐藏**，按钮下方一行小字说明检测到的 HDR 显示器数量。

### 4.5 配色方向（Apple 深色 Liquid Glass）

| 角色 | 色值 |
| --- | --- |
| 面板底色 | `rgba(28,28,30,0.72)` + blur(28px) saturate(160%) |
| 主文本 | `#F5F5F7` |
| 次级文本 | `rgba(235,235,245,0.55)` |
| 三次级文本 | `rgba(235,235,245,0.35)` |
| 分隔线 | `rgba(255,255,255,0.08)` |
| 控件填充 | `rgba(120,120,128,0.24)`（iOS 灰填充三级） |
| 强调色（滑块已填充、当前预设） | 系统蓝 `#0A84FF` |
| 危险/警告 | `#FF9F0A`（HDR 未开启） |
| 滑块轨道未填充 | `rgba(120,120,128,0.36)` |
| 滑块拇指 | `#FFFFFF` + `0 2px 8px rgba(0,0,0,.35)` |

### 4.6 交互细节

| 场景 | 行为 |
| --- | --- |
| 面板拖动 | 顶部栏 40px 区域为拖拽热区，拖动带 120ms 惯性回弹（越界吸附到屏幕内边距 12px） |
| 滑块拖动 | 拖动中实时写入（架构师做节流，建议 ≥30ms 间隔）；松手后再读一次系统值校正 |
| 预设切换 | 点击后滑块以 320ms spring 动画滑到目标值，同时写入一次 |
| 显示器切换 | 顶部下拉展开为 6px 圆角深色浮层，选中项左侧蓝色对勾；切换时面板内容 160ms 淡入淡出 |
| 失焦 | 默认点击面板外部即隐藏（160ms 淡出）；可在设置改为常驻 |
| 焦点 | 面板出现时**不抢焦点**（除用户在数值框内输入），避免打断当前工作 |

## 5. MVP 范围建议

**P0 全部 12 条 + P1-1/P1-2（多显示器，若 Q3/Q11 确认为多屏）+ P1-3（预设）+ P1-5（失焦可配）** 作为第一版交付；其余 P1/P2 放后续迭代。

**明确的非目标（Out of Scope）**
- 不做 HDR 开关本身的控制（仅读取状态 + 跳转系统设置）
- 不做显示器硬件 OSD 亮度/对比度控制
- 不做色彩管理/ICC/色域切换
- 不做任何联网与数据上报
