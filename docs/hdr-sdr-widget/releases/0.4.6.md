# 0.4.6：HDR 白色液位

## 更新内容

- 白色液位成为独立 HDR 亮度层，在 SDR 白色背景上也能通过亮度差区分。
- 液位主体使用 SDR 白点之上约 68% 的显示器可用亮度余量，表面亮线使用约 88%；按遮罩平滑合成，不整体抬亮桌面。
- 加强 HDR 状态的窄深色分界线；保留透明内缘阴影、液面曲率及已有动画。
- HDR 关闭或缺少亮度余量时使用原有 SDR 路径；显示器余量不足时，无法保证超白亮度差。

## 验证

39 项主程序测试通过（含 HLSL 编译）；TypeScript 检查和发布构建通过。对四类背景与五档液位导出浮点渲染结果。
本机显示器报告峰值 1015 nit，SDR 白点 272 nit。

| 液位 | 主体亮度（nit） | 相对 SDR 白点 |
|---|---:|---:|
| 25% | 722.5 | 2.656× |
| 50% | 724.38 | 2.663× |
| 75% | 726.25 | 2.67× |
| 100% | 726.25 | 2.67× |

0% 液位未填充区域为 271.875 nit。白底分界最低对比度约 5.31:1。

20 秒展开回归：已观测 159.98 fps，帧间隔 P95 6.251 ms，呈现统计存在 195 个观测缺口，因此不作为完整高刷验收通过的证明。

以上亮度为 scRGB 浮点像素换算值，不是光度计测量值；普通 PNG 会截断超白，不作为 HDR 亮度证据。端到端输入延迟、HDR 开关、跨刷新率、多显示器与长时稳定性未完成新一轮完整回归。

## 复测与安装

构建仍使用 src/hdr_sdr_widget/scripts/build.ps1。Material 模式导出的原始数据可用新增 scripts/analyze-liquid-hdr.py 核验液位亮度；脚本根据透明度寻找实际胶囊范围。
GitHub Release 提供单一 Windows x64 安装包、便携程序和 SHA256.txt。程序版本为 0.4.6，用户配置语义不变。
